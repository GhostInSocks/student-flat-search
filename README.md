# student-flat-search
 Interaktivni analitični zemjevid, ki študentom pomaga najti optimalno bivališče. Namesto fizične razdalje v kilometrih temelji na času potovanja do fakultete (z javnim prevozom, peš, s kolesom ali kombinacijo le-teh) ter na dejanskih skupnih stroških (najemnina + ocenjeni obratovalni stroški + vozovnica za prevoz).
